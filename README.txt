שלמה AI 5.0 — גרסת ניסוי בטוחה לאייפון

מה הוכן: v5.html הוא ממשק נפרד. האפליקציה הישנה (index.html) נשארת פעילה.

התקנה מהאייפון:
1. פתח את GitHub בדפדפן Safari ונווט אל https://github.com/abrvo3000-rgb/Shlomoqq
2. בחר Add file > Upload files והעלה רק v5.html (לא את קובץ ZIP).
3. לחץ Commit changes.
4. פתח https://abrvo3000-rgb.github.io/Shlomoqq/v5.html בדפדפן.
5. הצ'אט נטען מתוך Cloudflare Worker. אם iframe חסום, לחץ פתח צ'אט בחלון נפרד.

חשוב: האתר וה-Worker ציבוריים כרגע. יש להגן על ה-Worker במנגנון אימות לפני עבודה עם מידע אישי או שיתוף לאחרים. אין לשים מפתחות API בקובץ באתר. יכולות יצירת מדיה, מחקר אוטומטי, הודעות WhatsApp ואוטומציות ברקע עדיין לא מחוברות.

נתוני המוצרים והמשימות משתמשים במפתח ai-one-v2 הקיים, בתנאי שהקובץ נפתח באותו דומיין ובאותו דפדפן/הקשר אחסון. בצע גיבוי לפני שינוי נתונים.
