# שלמה AI 3.0 — iPhone PWA

העלה את ארבעת הקבצים `index.html`, `manifest.webmanifest`, `icon.svg`, `sw.js` לשורש המאגר הציבורי שכבר קיים ב-GitHub. החלף את הקבצים הקיימים (לא להעלות ZIP). GitHub Pages צריך להישאר על main / (root).

יכולות: ניהול משימות ומוצרים מקומי, מחקר דרך Google/Wikipedia/ChatGPT, יצירת פרומפטים וקישורים לשירותי יצירה חיצוניים, הקראה, הכתבה אם Safari תומך, ותזכורות רק כשהאפליקציה פתוחה. אין מנוע AI פנימי ואין יצירת תמונות או סרטונים בתוך האפליקציה. אין לשמור API keys בקוד GitHub Pages.

נתונים ישנים של v2 נשמרים באותו מקור localStorage; מומלץ לבצע גיבוי לפני עדכון. ייתכן שיידרש רענון האפליקציה כדי להחליף קבצים ששמורים במטמון.
